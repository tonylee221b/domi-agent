# 처음 방문할 때 준비할 것

서울대학교병원은 상급종합병원이다. 건강보험 급여를 적용받으려면 1단계 요양급여기관에서 발급한 요양급여의뢰서(진료의뢰서), 또는 상급종합병원 진료가 필요하다는 의사 소견이 적힌 건강진단·건강검진 결과서를 가져가야 한다. 서류 없이 진료는 받을 수 있지만 건강보험 급여가 적용되지 않으며, 나중에 제출해도 이전 진료에 소급 적용되지 않는다.

처음 진료를 받는 사람은 신분증과 진료의뢰서를 지참하고 진료신청서를 작성해 원무접수·수납창구에 제출한다. 다른 병원의 영상 CD가 있으면 진료 전에 등록한다.

# 접수와 예약

- 방문 접수: 평일 08:00~18:00, 토요일 08:00~13:00
- 전화 예약센터: 1588-5700, 평일 09:00~18:00, 토요일 09:00~13:00
- 인터넷·앱 예약: 24시간 이용 가능

성인은 본관 1층 또는 대한외래 지하 2·3층, 어린이는 어린이병원 1층, 암 환자는 암병원 1층의 원무접수·수납창구를 이용한다.

# 예외와 확인 사항

가정의학과, 응급·분만 환자 등 일부 경우에는 진료의뢰서가 필요하지 않다. 의료급여 환자는 의뢰서 발급 기관과 유효기간 조건이 별도로 있으므로 원문 또는 예약센터에서 확인한다.
