# 병원 조회 지원 지역

도미의 병원 조회는 건강보험심사평가원 병원정보서비스의 시·도 코드를 사용한다.
현재 지원 지역은 서울, 부산, 인천, 대구, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주이다.

수원, 성남, 천안, 청주, 전주, 춘천, 강릉, 포항, 창원처럼 시·군·구 단위의 지역은 직접 선택하거나 조회할 수 없다.
이 경우 수원·성남은 경기, 천안은 충남, 청주는 충북, 전주는 전북, 춘천·강릉은 강원, 포항은 경북, 창원은 경남을 선택하도록 안내한다.

# Supported hospital regions

Domi searches hospitals using province-level codes from the HIRA Hospital Information Service.
Supported regions are Seoul, Busan, Incheon, Daegu, Gwangju, Daejeon, Ulsan, Sejong, Gyeonggi, Gangwon, North Chungcheong, South Chungcheong, North Jeolla, South Jeolla, North Gyeongsang, South Gyeongsang, and Jeju.
City or district names are not direct search options; guide the user to select the corresponding province.
