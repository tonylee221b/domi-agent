# 경로 할인

만 65세 이상은 KTX, ITX-마음, 새마을호, 무궁화호 등에서 운임의 30%를 할인받을 수 있다. KTX, ITX-마음, 새마을호의 경로 할인은 토요일·일요일·공휴일에는 적용되지 않는다. 무궁화호 이하 열차의 경로 할인은 주말·공휴일에도 적용되며, 통근열차 할인율은 50%다.

# 공통 유의사항

- 할인은 운임에 적용되며 특실·우등실 등의 요금에는 적용되지 않는다.
- 다른 영업 할인과 중복 적용되지 않는다.
- 본인에게 발급된 기명식 할인 승차권을 사용할 때 신분증 제시를 요구받을 수 있다.
- 실제 적용 가능 여부와 최종 금액은 승차권 조회·구매 시점에 다시 확인한다.

코레일은 2026년 2월 1일 기준 할인 안내에서도 만 65세 이상 경로 할인 30%와 주말·공휴일의 일부 열차 제외 조건을 안내한다.
